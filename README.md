# Popote

Menus de la semaine, gamelles et congélateur, liste de courses en panier et budget alimentaire, à partir du cahier de recettes.

- Application web installable (Android : Chrome, « Installer l'application »), utilisable hors connexion.
- Les menus, dépenses et stocks restent sur le téléphone (Stock, Sauvegarde pour exporter ou importer).
- data/recettes.json et data/ingredients.json : recettes et prix, mis à jour depuis le cahier de recettes.
